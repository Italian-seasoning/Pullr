# Playback Insights Intent

- Requested outcome: accurate playback-only lifetime and weekly insights from combined Chrome and Comet activity.
- Scope: browser playback gating, compatible local event identity, weekly aggregation, chart and disclosure UI, automated and runtime verification.
- Non-goals: accounts, cloud sync, recommendations, general screen time, protected-player bypass, browser-by-browser reporting.
- Baseline refs: approved design, implementation plan, initial baseline, current source.
- Baseline usage: all required refs acknowledged and cited; none missing; continue.
- Risk hints: iframe playback, service-worker lifecycle, JSONL compatibility, calendar boundaries, Comet native-messaging registration.
- Stop: done with automated and available runtime evidence; otherwise needs-verification, blocked, or scope-exceeded with the boundary named.
- Execution readiness: matches the plan's intent, scope, compatibility, retirement, testing, and review locks.
